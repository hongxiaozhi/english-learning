# English Learning Project

A personal project to improve English skills.

## Goals
- Improve reading comprehension
- Correct grammar and spelling errors
- Build and memorize vocabulary
- Prepare for English exams

## Folder Structure
- `exam-pdfs/` — exam papers
- `vocabulary/` — word lists (words I don't know)
- `memory/` — spaced repetition review
- `reading/` — reading practice materials
- `grammar/` — error log and grammar notes
- `notes/` — study notes

## How to Use
- Chat with Claude to practice English
- Claude corrects errors and adds new words to vocabulary
- Review words regularly using the memory folder
